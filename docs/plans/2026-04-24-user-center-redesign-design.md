## 1. 设计系统基础

### 1.1 配色方案（基于 DESIGN.md）

| Token | 色值 | 用途 |
|-------|------|------|
| `--color-bg` | `#f5f4ed` (Parchment) | 页面背景 |
| `--color-surface` | `#faf9f5` (Ivory) | 卡片/容器背景 |
| `--color-primary` | `#c96442` (Terracotta) | 主按钮/强调色 |
| `--color-text` | `#141413` (Near Black) | 主文字 |
| `--color-text-secondary` | `#5e5d59` (Olive Gray) | 次要文字 |
| `--color-border` | `#f0eee6` (Border Cream) | 边框 |
| `--color-surface-dark` | `#30302e` (Dark Surface) | 深色表面 |

### 1.2 字体

- 标题：`Georgia`（Serif），weight 500
- 正文/UI：`system-ui, -apple-system, Arial`（Sans）
- 行高：标题 1.10-1.30，正文 1.60

### 1.3 圆角

- 按钮/输入框：12px
- 卡片：8px
- 大容器：16-32px

### 1.4 阴影

- 卡片：`0px 4px 24px rgba(0,0,0,0.05)` (whisper)
- 交互态：`0px 0px 0px 1px` ring shadows（暖色调）

### Sidebar 设计

- 宽度：220px

- 菜单项：左侧 2px Terracotta 选中指示条
- hover：Warm Sand 背景

### 3.2 账户设置页面 (AccountSetting.vue)

**布局：双栏表单 + 实时预览**

- 输入框：12px 圆角，focus 时 2px Focus Blue ring
- 保存按钮：Terracotta 背景，8px 圆角
- 实时验证：手机号/邮箱格式校验
- 新增：修改密码区块

### 3.3 诊断历史页面 (DiagnosisHistory.vue)

**布局：筛选栏 + 图表 + 数据表格**

- 时间趋势图表：折线图，展示每月诊断量
- 疾病分布图表：饼图，展示各疾病占比
- 日期范围选择器
- 状态下拉：全部/已完成/进行中/已取消
- 诊断ID/结果文字搜索
- 批量选择 + 批量导出

### 3.4 通知中心 (新增)

**位置：** Sidebar 新增菜单项 + 顶部铃铛图标

**通知类型**
- 诊断报告完成（蓝色）
- 复审状态更新（绿色）
- 系统通知（灰色）

## 4. 响应式设计

| 断点 | 宽度 | 布局变化 |
|------|------|----------|
| Desktop | ≥992px | 双栏布局 |
| Tablet | 768-991px | Sidebar 收起为图标模式 |
| Mobile | <768px | Sidebar 变为顶部 Tab |
