## 采集口径

- 真实 React 页面（`web/`），本地后端 `:8081` + Vite `:5182`，管理员会话。
- 浏览器：Playwright Chromium（本机 1234 构建，`E2E_CHROMIUM_PATH` 可覆盖）。
- 截图内数据来自本地数据库，未手工填充；仪表盘所选窗口内判读为 0，
  因此趋势与分布展示的是**解释型空态**，不是伪造数据。
- 测试完成后已清理本次生成的文章，未改动业务数据。

## 边界

截图与自动化通过 **不等于** 用户视觉验收通过。最终视觉结论以人工复核为准。
