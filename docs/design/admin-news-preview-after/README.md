# 管理端资讯完整文章预览 · 截图证据（PR-B）

真实运行系统的截图：`web/`（Vite，:5184）+ 本任务共享的后端（:8083）+ 本地 MySQL。
没有 ImageGen、没有静态 HTML 模拟、没有手工改状态；文章标题、正文、封面、字数、
章节数都来自真实表单与接口。

- 采集脚本：`web/scripts/evidence/admin-news-preview.mjs`（主套件）+
  `admin-news-preview-gap.mjs`（复杂排版 / 无封面补采），Playwright，Chromium 1234
- 预览证据用的是**临时草稿**（标题带「【预览验证】」）：主套件自己建草稿并经真实
  `/api/news/edit` 与 `/api/news/uploadCover` 写入封面，采集结束即删，不留在库里
  （每次跑完脚本都会列库核对「预览验证」残留为 0）。
- 脚本会在预览期间监听网络：一旦出现 `POST /news/edit` 或 `POST /news/uploadCover`
  就以退出码 3 失败。本轮所有截图采集均退出码 0（**预览没有保存、没有改状态**）。
- 截图**不等于**人工视觉签收。

## 已知取舍

1. **眉线按发布状态走**：只有 `status=1`（已发布）才沿用真实发布时间；草稿 / 待审核 /
   下架即使带着 publishTime 也一律显示「预览稿 · 尚未发布，公开页不会出现」——
   旧逻辑看 publishTime 存在性，会让待审核 / 下架文章冒充「已上线」。
2. **摘要不是独立字段**：后端保存时按「剥标签后的正文前 30 字」生成摘要，表单里没有
   摘要输入框。预览在文章上方显示同一口径的 30 字读数，不足 30 字时如实说「保存会被
   拒绝」，不虚构一个摘要字段。
3. **预览时隐藏右侧发布设置栏**：编辑区两栏只有 676px，塞不下公开页 900px 以上的
   桌面版式。切到预览把右栏收起，桌面预览才是真桌面宽度；保存按钮仍在工具行。
   有未保存修改时预览栏会多一行「有未保存修改，发布设置栏已隐藏」，不给无提示的
   不可达状态。
4. **手机预览是容器查询，不是缩小版**：公开页断点按浏览器宽度生效，桌面视口缩框
   不会触发移动版式，所以设备框用 `container-type: inline-size` 补同样的断点。
5. **桌面预览宽度与公开页的差（如实记录）**：公开页文章列是 `.wrap` 的
   `--maxw: 1240px` 减 40px 双内边距 = 1160px 内容宽；管理端 1440 视口下工作区
   主列只有约 1020px（侧栏 248 + 管理端内边距），设备框再宽也受父容器限制。
   设备框上限已对齐 `--maxw: 1240px`——在 ≥1488px 视口（1920 证据图）设备框
   真的到 1240；1440 及以下差的是管理端版型本身，不是组件。组件与 CSS 与公开页
   是同一份（`NewsArticleView` + `news.css`），排版规则零差异。
6. **摘要读数口径**：摘要条显示「剥标签后正文前 30 字」，与后端 `buildSummary`
   同管线；Markdown 预览里 `&amp;` 类实体在渲染时被还原，字数与后端对已落库
   HTML 的统计最多差在实体字符上（`NewsArticleView` 文件注释有写）。
7. **字数按渲染后全文算**：Markdown 源的 `#`、`**`、`-` 记号不计入字数，与公开页
   「数库里存的 HTML」同口径；被提走的导语与挤出正文的标题仍在全文里，不多算
   也不少算（单测断言 402 / 483 两个真实读数）。
8. **同屏两个数字是两种口径，不是少了几十字**：文章眉线的「N 字」是公开页同口径的
   `newsWordCount`（汉字按字、拉丁按词）；编辑区那一侧的「N 字符」是后端
   「正文至少 30 字」守卫用的可见字符数（剥标签后的正文长度）。所以同屏 154 字符
   对 135 字是正常的——两边服务的目的不同。界面因此把编辑器侧一律写成「字符」，
   不让两个「字」混在一起。
9. **容器断点分三档**：900 / 768 两档与 `news.css` 一一对应（768 档 = 纸面内边距
   18px + 目录 44px 触控），另加 480 档纯手机微调（封面圆角与限高 260px），
   只影响手机预览观感，不对应公开页断点。公开页没有 480 档——预览多这一档是刻意的
   设备框调校，不是漏抄。
10. **作者兜底两侧不同**：作者取库里 `author` 字段（两侧同源）；公开页缺作者时
    显示「编辑部」，管理端预览显示「未署名」——预览面对的是还没发布的稿子，
    「未署名」比「编辑部」诚实。这是唯一的文案差异，不影响版式。
