## 二、UI / UX 改动

- **口径写进界面**：每一处数字都标明范围（窗口内 vs 全站）。这轮最实质的改动不是配色，
  是把「同一个页面里混着两种时间范围」这件事从读者脑子里搬到屏幕上。
- **不虚构**：无 mock、无手工填充、无假曲线；缺读数给「—」而不是 0。
- **语义色不顶替**：管理紫只表示管理身份 / 当前态；医学严重度与复核状态一律 `--risk-*`，
  且**必须同时带文字标签**（颜色不是唯一信息载体）。
- **图表第二通道**：图例 + 直标 + 读数表齐备；分类色只用于 Management / Intelligence 图表。
- **共享原语，不造第二套**：复用 `AdminLayout` / `AdminPageHead` / `DataTable` / `RowMenu` /
  `Modal` / `Drawer` / `BatchBar` / `AdminEmpty` / `FaultNote` 与既有令牌。新增两个共用件：
  `MetricCell`（KPI 读数格）、`InsightEmpty`（空窗口解释面板）。
- **响应式**：≤900px 台账卡片化（一条记录一屏可读），≤640px 筛选折叠；四档视口均无横向溢出。
