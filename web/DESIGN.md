# web/ · 设计规则速查

> 本目录是 Iris 的**产品前端**（React 19 + Vite + Tailwind v4）。
> 完整设计系统在仓库根的 `DESIGN.md`（**Iris 2.0 · Adaptive Visual System**，目标规范）；
> **色值一律以 `src/styles/tokens.css` 为准**（已实现的事实）。
> 本文只记 `web/` 相关的规则与速查，**不抄数值**——抄下来就会漂。

## 方向

**同一套品牌身份，四种表达强度**：Brand（首页）/ Management（管理端）/
Intelligence（Agent 与影像工作台）/ Clinical（诊断与判读）。
场景决定圆角、主色与动效预算；**没有"全站通用"的一套控件外观**。
细则见根 `DESIGN.md` §1–§4。

## 规则（写代码时必须遵守）

1. **先定场景再写样式**：Clinical 用直角 + 墨色主 CTA + 信号橙语义；
   Management 用 8–12px 圆角 + 钴蓝主操作 + 分类数据色；
   Brand 用 24–38px 圆角 + 玻璃材质 + 钴蓝；
   Intelligence 用 12px 圆角 + 运行态蓝/青。**组件变体矩阵见根 `DESIGN.md` §4。**
2. **三套语义色互不顶替**：`--signal`（临床重点/当前态）、`--brand-*`（品牌身份）、
   `--risk-*`（医学严重度）。信号橙**不是主 CTA 色**、不大面积填充；
   承载文字时用 `--signal-text`（纸面 `#bd4515`，暗底 `#ef7a45`）——`--signal`
   的对比度不够做正文色。
3. **严重度与品牌解耦**，永远同时给文字标签（`RiskTag`）。颜色不是唯一信息载体。
4. **一切数字用 `--font-mono` + `tabular-nums`**：置信度、概率、计数、耗时、时间戳、哈希。
5. **衬线标题 weight 只允许 400**（`--font-serif`）。禁 700+、禁斜体。
   品牌拉丁字用 `--font-brand`（Manrope，**无汉字，不许兜底中文**）。
6. **圆角只用令牌梯** `--radius-none/sm/md/lg/xl/2xl/circle/pill`，按场景取，
   不写像素自由值，不堆圆角。
7. **发丝线优先于阴影**。需要抬升用极淡的墨色阴影，禁用纯黑投影
   （品牌玻璃用 `--brand-shadow`）。
8. **纸面原语 `--paper-*` 不参与主题翻转**：判读记录在任何主题下都是同一张白纸。
9. **装饰必须服从信息**：不用粒子、扫描线、光环、圆形渐变、居中大标题。
   循环动效只在**绑定真实状态**时允许，且离屏即停、`prefers-reduced-motion`
   **实时订阅**当场停、可手动暂停。
10. **不虚构业务能力**：界面上的每个数字都能追到后端端点与口径；
    **设计稿里有 ≠ 产品里有**。
11. **术语**：界面用「判读」，不是「诊断」；只有「诊断 Agent」保留为产品名。
12. **口径**：置信度一律百分比一位小数，缺省 `—`；分页量与全量不得混排而不标注。

## 上下文令牌

组件只消费 `--fg / --fg-2 / --fg-3 / --bg / --hr / --hr-strong` 这组别名，
它们由 `.is-field / .is-sheet / .is-dark / .is-night` 定义。
**不要**在组件里直接读 `--ink / --line`（那会绕过主题与纸面翻转）。
品牌面另加 `.iris2` 语境类；管理面 `.is-admin`、工作台面 `.is-console`
**尚未实现**，别提前写依赖它们的样式。

## 已知债务

根 `DESIGN.md` §8 有完整清单。改到这些地方时顺手修，不要照着复刻：

- Tailwind v4 的 `.overline` 工具类给眉线多加一条上划线；
- 断点未完全收敛（各页 `@media` 有 17 个不同取值），新代码只用 §3.6 五档；
- 管理端仍是旧 B 档外观（主按钮墨色、0 圆角；信号橙只做当前态与焦点环），与新规范不一致；
- `--brand-*`令牌与 `.iris2` 随 PR #52 进入 `tokens.css`，合并前取不到；
- **仍有 3 处 `outline: none`**：`CardSwap.css` 的装饰容器、
  `admin.css` 里 Recharts 图表 wrapper 的 `:focus`、`app.css` 的账号菜单面板。
  前两处是装饰/弹层容器（焦点不在其上），**Recharts 那处会让图表聚焦时没有
  可见焦点环**——要改成可见焦点样式，不要留着。

2026-11-10 验收批次已修掉的（别再当成债，也别照着复刻旧写法）：

- 正文三级色曾只有 2.89:1——现已提到 4.5:1（`--paper-ink-3: #676e72`，
  `--on-dark-3: #8d948f`）；
- 橙色文字改走 `--signal-text`（纸面 `#bd4515`），`--signal` 只做标记与边框。
