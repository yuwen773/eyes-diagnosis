# 年龄相关性黄斑变性（AMD）

## 概述

年龄相关性黄斑变性（Age-related Macular Degeneration，AMD）是一种随年龄增长而发生的黄斑区退行性病变，是导致50岁以上人群中心视力下降的主要原因之一。AMD 主要影响黄斑区，导致中心视野缺损，严重影响阅读、驾驶和识别面部等日常活动。

## 分类

### 干性AMD（非渗出性AMD）
- **特征**：黄斑区出现玻璃膜疣（drusen）和色素上皮改变
- **占比**：约80-90%的AMD患者属于干性
- **进展**：通常进展缓慢，可逐渐发展为湿性AMD
- **症状**：中心视力逐渐下降、视物变形、阅读困难

### 湿性AMD（渗出性AMD）
- **特征**：脉络膜新生血管（CNV）形成，导致黄斑水肿、出血
- **占比**：约10-20%的AMD患者，但造成80%以上的严重视力丧失
- **进展**：进展迅速，若不及时治疗可在数周内严重损害视力
- **症状**：突发性视力下降、视物变形、中心暗点、颜色感知改变

## 诊断要点

### 眼底检查特征
- **玻璃膜疣**：大小不等、边界不清的黄色沉积物，位于视网膜色素上皮层
- **色素改变**：黄斑区色素聚集或脱失
- **萎缩性改变**：地图样萎缩（GAA）
- **新生血管**：FFA检查可见荧光渗漏
- **出血水肿**：OCT检查可见视网膜下液、神经上皮脱离

### 辅助检查
1. **光学相干断层扫描（OCT）**：评估黄斑厚度、视网膜层间结构
2. **眼底荧光血管造影（FFA）**：显示新生血管范围和渗漏情况
3. **吲哚菁绿血管造影（ICGA）**：更清晰显示脉络膜循环
4. **Amsler表**：检测中心视野缺损和视物变形

## 高危人群

- 年龄≥50岁
- 吸烟史（吸烟者患病风险增加2-4倍）
- 有AMD家族史
- 长期暴露于强紫外线环境
- 高脂饮食、肥胖
- 心血管疾病患者

## 治疗方案

### 干性AMD
- **营养补充**：AREDS2配方（维生素C、维生素E、叶黄素、玉米黄质、锌、铜）
- **生活方式**：戒烟、控制血压、健康饮食、多摄入深色蔬菜和鱼类
- **监测随访**：定期Amsler表自测、OCT监测

### 湿性AMD
- **抗VEGF治疗**（一线治疗）：
  - 雷珠单抗（Ranibizumab）
  - 阿柏西普（Aflibercept）
  - 贝伐单抗（Bevacizumab）
  - 康柏西普（Conbercept）
- **治疗方案**：初始每月注射一次，连续3个月，后根据病情延长间隔
- **光动力疗法（PDT）**：适用于特定类型患者

## 日常防护

1. **戒烟**：最重要的可控危险因素
2. **紫外线防护**：佩戴防紫外线太阳镜
3. **健康饮食**：多摄入深绿色蔬菜、鱼类、坚果
4. **控制体重和 血压**
5. **定期眼科检查**
6. **Amsler表自测**：每日测试，发现异常及时就诊
