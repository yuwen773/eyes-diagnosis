# 糖尿病视网膜病变（Diabetic Retinopathy，DR）

## 概述

糖尿病视网膜病变（Diabetic Retinopathy，DR）是糖尿病最常见的微血管并发症之一，也是工作年龄人群首位致盲性眼病。长期高血糖状态导致视网膜微血管损伤，引起血管渗漏、出血、新生血管形成等病理改变，最终可能导致视网膜脱离和失明。

## 流行病学

- 糖尿病患者中DR患病率约为30-40%
- 增殖期DR约占糖尿病视网膜病变的10-15%
- 病程10年以上的1型糖尿病患者中，增殖期DR患病率可达50%以上
- 2型糖尿病患者中，DR患病率与血糖控制水平、病程密切相关

## 发病机制

### 病理生理
1. **周细胞丢失**：高血糖导致视网膜毛细血管周细胞选择性地丢失
2. **基底膜增厚**：糖萼沉积导致毛细血管基底膜增厚
3. **内皮细胞损伤**：血-视网膜屏障破坏，通透性增加
4. **微血管瘤形成**：毛细血管壁薄弱部位膨出形成
5. **新生血管形成**：缺氧诱导因子（HIF）和血管内皮生长因子（VEGF）上调

## 临床分期

### 非增殖期糖尿病视网膜病变（NPDR）

**轻度NPDR**
- 眼底仅有微血管瘤
- 无其他明显异常

**中度NPDR**
- 微血管瘤、出血点、硬性渗出
- 棉绒斑（视网膜神经纤维层缺血性梗死）
- 可存在IRMA（视网膜内微血管异常）

**重度NPDR**
- 4个象限中任一象限出血点/微血管瘤≥20个
- 至少2个象限出现明确的静脉串珠
- 至少1个象限出现IRMA
- **增殖期前期的"4-2-1"原则**

### 增殖期糖尿病视网膜病变（PDR）

**特征性改变**
- 新生血管形成（NVE）：出现在视网膜表面
- 新生血管性青光眼（NVG）：新生血管长入前房角
- 纤维血管膜形成
- 玻璃体出血
- 牵拉性视网膜脱离

## 糖尿病黄斑病变（DME）

- **定义**：黄斑区视网膜增厚或硬性渗出累及黄斑中心500μm区域
- **分类**：
  - 弥漫性黄斑水肿：毛细血管渗漏广泛累及黄斑
  - 囊样黄斑水肿：呈花瓣状囊腔改变
  - 缺血性黄斑病变：黄斑毛细血管无灌注

## 诊断要点

### 眼底检查
1. **彩色眼底照相**：记录病变范围和程度
2. **荧光素眼底血管造影（FFA）**：
   - 显示无灌注区范围
   - 评估新生血管活动性
   - 指导激光治疗部位
3. **光学相干断层扫描（OCT）**：
   - 定量测量黄斑厚度
   - 评估黄斑水肿类型
   - 监测治疗反应

### 筛查标准
- 1型糖尿病：确诊后5年内开始筛查
- 2型糖尿病：确诊时即进行首次筛查
- 妊娠糖尿病：妊娠前或妊娠早期筛查

## 治疗方案

### 全身管理
- **严格控制血糖**：HbA1c<7%
- **控制血压**：<140/90mmHg
- **调节血脂**：他汀类药物
- **改善微循环**

### 眼科治疗

**激光治疗**
- **全视网膜光凝（PRP）**：适用于高危PDR
- **黄斑格栅样光凝**：适用于弥漫性DME
- 作用机制：破坏缺氧视网膜，降低VEGF表达

**抗VEGF治疗**（一线治疗）
- 雷珠单抗（Ranibizumab）
- 阿柏西普（Aflibercept）
- 康柏西普（Conbercept）
- 治疗方案：每月一次，连续3-5次，后按需治疗

**糖皮质激素治疗**
- 玻璃体腔注射曲安奈德
- 适用于抗VEGF治疗无效的DME
- 注意继发性青光眼和白内障进展

**手术治疗**
- 玻璃体切除术：适用于玻璃体出血不吸收、牵拉性视网膜脱离

## 随访建议

| 分期 | 随访间隔 |
|------|---------|
| 无DR | 1-2年 |
| 轻度NPDR | 1年 |
| 中度NPDR | 6-12月 |
| 重度NPDR | 3-6月 |
| PDR | 1-3月 |

## 患者教育要点

1. 强调血糖、血压、血脂综合控制的重要性
2. 告知患者定期眼科随访的必要性
3. 教会患者自我监测：Amsler表使用
4. 识别"危险信号"：突然视力下降、眼前漂浮物增多
5. 戒烟：吸烟加速DR进展
