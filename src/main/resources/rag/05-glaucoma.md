# 青光眼（Glaucoma）

## 概述

青光眼（Glaucoma）是一组以视神经萎缩和视野缺损为共同特征的疾病，眼内压增高是其主要危险因素，但也有正常眼压青光眼类型。青光眼是全球首位不可逆性致盲眼病，由于视神经损害不可逆转，早期发现、早期治疗对于保护视功能至关重要。

## 流行病学

- 全球约7600万青光眼患者
- 40岁以上人群患病率约为2-3%
- 约50%的青光眼患者不知道自己患病
- 双眼发病，最终可导致双眼失明

## 分类

### 原发性青光眼

**原发性闭角型青光眼（PACG）**
- 前房角关闭导致房水引流受阻
- 急性发作：眼痛、头痛、视力下降、恶心呕吐
- 慢性进展：前房角逐渐关闭，眼压缓慢升高

**原发性开角型青光眼（POAG）**
- 前房角开放但小梁网引流功能障碍
- 进展缓慢，早期多无症状
- 眼压升高（正常眼压10-21mmHg）

### 继发性青光眼
- 眼部疾病引起：葡萄膜炎、外伤、肿瘤
- 药物引起：糖皮质激素
- 新生血管性青光眼（NVG）：糖尿病视网膜病变等缺血性疾病引起

### 先天性青光眼
- 胚胎发育异常导致前房角结构异常
- 发生在婴幼儿（牛眼、水眼）

## 发病机制

### 眼压升高机制
- **开角型**：小梁网变性、硬化、阻力增加
- **闭角型**：瞳孔阻滞、周边虹膜堆积、前房角关闭

### 视神经损害机制
- **机械学说**：眼压直接压迫视神经纤维
- **血管学说**：视盘血流灌注不足
- **综合因素**：神经营养因子缺乏、谷氨酸毒性、氧化应激

## 诊断要点

### 眼压检查
- **正常眼压范围**：10-21mmHg
- **24小时眼压曲线**：发现眼压波动规律
- **眼压波动**：正常人双眼差值<5mmHg，昼夜差值<8mmHg

### 视神经评估
1. **眼底彩照**：记录视杯视盘比（CDR）
   - 正常CDR：0.3-0.5
   - 青光眼杯凹：偏心性扩大、 rim narrowing

2. **光学相干断层扫描（OCT）**
   - 视网膜神经纤维层（RNFL）厚度变薄
   - 视盘参数分析

3. **视野检查**
   - 早期：旁中心暗点、鼻侧阶梯
   - 中期：弓形暗点、环形暗点
   - 晚期：管状视野、中心视力丧失

### 前房角检查
- **超声生物显微镜（UBM）**：显示前房角结构
- **前房角镜**：评估前房角开放程度

### 青光眼分期诊断标准

| 分期 | 视野改变 | 特征 |
|------|---------|------|
| 疑似期 | 无 | CD比增大或RNFL缺损，但无视野损害 |
| 早期 | 旁中心暗点、鼻侧阶梯 | 视野缺损在中心5°以外 |
| 中期 | 弓形暗点 | 视野缺损累及中心5° |
| 晚期 | 管状视野 | 视野<10°，但中心视力保留 |
| 绝对期 | 全盲 | 无光感 |

## 治疗方案

### 药物治疗（首选）

**降眼压药物**
1. **前列腺素类似物**（一线）
   - 拉坦前列素（Latanoprost）
   - 曲伏前列素（Travoprost）
   - 用法：每日一次，傍晚滴眼

2. **β受体阻滞剂**
   - 噻吗洛尔（Timolol）
   - 注意：哮喘、心动过缓、心衰患者禁用

3. **碳酸酐酶抑制剂**
   - 布林佐胺（Brinzolamide）
   - 派立明（Dorzolamide）

4. **α受体激动剂**
   - 溴莫尼定（Brimonidine）

5. **复方制剂**
   - 适利达（Latanoprost + Timolol）
   - 派立噻（Dorzolamide + Timolol）

### 激光治疗
- **选择性激光小梁成形术（SLT）**：开角型青光眼
- **激光虹膜周切术（LPI）**：闭角型青光眼
- **激光睫状体光凝术**：难治性青光眼

### 手术治疗
- **小梁切除术**：经典滤过手术
- **引流阀植入术**：难治性青光眼
- **微分流器植入**：新型手术方式
- **睫状体光凝术**：绝对期青光眼

## 随访监测

1. **眼压监测**：目标眼压设定后定期测量
2. **视野检查**：每6-12月一次
3. **OCT检查**：每6-12月一次，监测RNFL变化
4. **眼底照像**：记录视神经改变

## 高危人群筛查

- 40岁以上人群
- 有青光眼家族史
- 高度近视（>600度）
- 长期使用糖皮质激素
- 糖尿病、高血压患者
- 既往眼部外伤史
