# 白内障（Cataract）

## 概述

白内障（Cataract）是指晶状体混浊导致的视觉障碍性疾病。晶状体位于虹膜和玻璃体之间，正常情况下是透明的，当其发生混浊时会阻挡光线进入眼内，导致视力下降。白内障是全球首位致盲性眼病，也是我国防盲治盲工作的重点。

## 病因分类

### 年龄相关性白内障（老年性白内障）
- **发病机制**：随着年龄增长，晶状体蛋白质发生变性、氧化应激损伤
- **发病年龄**：通常在50岁以后开始出现，70岁以上人群患病率超过60%
- **进展特点**：双眼可先后发病，进展缓慢

### 先天性白内障
- **病因**：遗传因素、宫内感染（如风疹病毒）、代谢障碍（如半乳糖血症）
- **特点**：出生时或婴幼儿期即存在
- **影响**：可导致形觉剥夺性弱视，需尽早处理

### 代谢性白内障
- **糖尿病性白内障**：血糖波动导致晶状体渗透压改变
- **手足抽搐性白内障**：低钙血症引起
- **Wilson病相关性白内障**：铜代谢异常

### 外伤性白内障
- **病因**：眼球钝挫伤、穿通伤、辐射伤、电击伤
- **特点**：可立即发生或延迟出现，形态多样

### 药物性白内障
- **糖皮质激素**：长期大剂量使用可导致后囊下白内障
- **氯丙嗪**、**三苯氧胺**等

### 并发性白内障
- **眼部疾病**：葡萄膜炎、青光眼、视网膜色素变性
- **全身疾病**：糖尿病、甲状腺功能异常

## 临床分型

### 按混浊部位分类
1. **皮质性白内障**：最常见（70%），从晶状体周边向中央发展
2. **核性白内障**：混浊位于晶状体核层，进展缓慢
3. **后囊下白内障**：后囊膜下浅层混浊，早期即可严重影响视力
4. **完全白内障**：晶状体全部混浊

### LOCS III分级系统
- **核颜色（NC）**：0-6级
- **核混浊度（NO）**：1-6级
- **皮质混浊（C）**：1-5级
- **后囊下混浊（P）**：1-5级

## 症状与体征

### 主要症状
- **进行性视力下降**：是最主要症状，往往数月至数年逐渐加重
- **视物模糊**：如同透过毛玻璃看东西
- **屈光改变**：可出现近视度数增加或远视漂移
- **单眼复视或多视**：晶状体不均匀混浊导致
- **眩光**：夜间或强光下视力明显下降
- **颜色感知改变**：色彩饱和度降低，色调偏黄

### 眼底检查
- **未成熟期**：晶状体混浊，眼底尚可窥见
- **成熟期**：晶状体完全混浊呈乳白色，眼底无法窥入
- **过熟期**：晶状体皮质液化、核下沉

## 诊断要点

1. **视力检查**：远近视力均下降，验光无有效矫正
2. **裂隙灯检查**：直接观察晶状体混浊部位、范围和程度
3. **眼底检查**：排除其他眼底病变
4. **眼压测量**：排除继发性青光眼（晶体源性青光眼）
5. **人工晶体度数测量**：为手术做准备（IOL Master、角膜地形图）

## 治疗方案

### 药物治疗
- **适应症**：仅适用于早期患者或暂不具备手术条件者
- **常用药物**：吡诺克辛滴眼液、白内停等（疗效有限）
- **注意**：目前尚无有效药物能逆转白内障混浊

### 手术治疗（唯一有效治疗方法）

**手术指征**：
- 视力下降影响日常生活和工作
- 最佳矫正视力≤0.5
- 晶状体混浊影响眼底疾病诊治
- 晶体源性炎症或青光眼

**手术方式**：
1. **白内障超声乳化吸除术联合人工晶体植入术**（主流术式）
   - 切口：2.2-3.0mm透明角膜切口
   - 特点：创伤小、恢复快、散光小

2. **白内障囊外摘除术联合人工晶体植入术**
   - 适用于V-VI级核硬化或晶状体半脱位

3. **飞秒激光辅助白内障手术（FLACS）**
   - 精确度更高，适合高端需求患者

**人工晶体（IOL）选择**：
- 单焦点IOL：看远或看近
- 多焦点IOL（双焦点、三焦点）：同时满足远、中、近视力
- 散光矫正型IOL（Toric IOL）：矫正角膜散光
- 可调节IOL：模拟自然晶状体调节能力

## 预防措施

1. **避免长期紫外线暴露**：佩戴防紫外线太阳镜
2. **控制血糖**：糖尿病患者严格控制血糖
3. **戒烟**：吸烟增加患病风险
4. **健康饮食**：多摄入富含维生素C、E、胡萝卜素的食物
5. **慎用糖皮质激素**：避免长期大剂量使用
6. **积极治疗全身疾病**
