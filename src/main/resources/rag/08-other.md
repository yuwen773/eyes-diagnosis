# 其他眼底疾病（Other Fundus Diseases）

## 概述

在临床实践中，眼底疾病种类繁多，除前述七种常见疾病外，还有多种可表现为眼底异常改变的疾病。这些疾病可能累及视网膜、脉络膜、视神经或玻璃体，其眼底表现可能与前述疾病相似或重叠，需要结合全身情况、详细病史及多种检查手段进行鉴别诊断。

## 常见其他眼底疾病

### 视网膜血管性疾病

**视网膜静脉阻塞（RVO）**
- **分类**：分支静脉阻塞（BRVO）、中央静脉阻塞（CRVO）
- **表现**：
  - 沿静脉分布的火焰状出血
  - 静脉迂曲、扩张
  - 棉绒斑、黄斑水肿
- **并发症**：新生血管性青光眼（NVG）、黄斑水肿
- **治疗**：
  - 抗VEGF治疗（黄斑水肿）
  - 全视网膜光凝（缺血型预防NVG）
  - 糖皮质激素治疗

**视网膜动脉阻塞（RAO）**
- **表现**：突然无痛性视力下降、后极部视网膜苍白水肿、"樱桃红点"
- **治疗**：属于眼科急诊，需争分夺秒抢救
- **预后**：差，需警惕对侧眼发病

**视网膜血管炎**
- **病因**：感染、自身免疫、肿瘤
- **表现**：血管鞘、血管周围炎、血管闭塞
- **治疗**：针对病因，糖皮质激素治疗

### 葡萄膜疾病

**葡萄膜炎相关眼底改变**
- **前葡萄膜炎**：睫状充血、KP、房闪
- **中间葡萄膜炎**：雪球样混浊、睫状体平坦部雪堤样改变
- **后葡萄膜炎**：视网膜或脉络膜浸润病灶
- **全葡萄膜炎**：VKH综合征、Behcet病等

**Vogt-小柳-原田综合征（VKH）**
- **特点**：双眼全葡萄膜炎，伴有神经系统症状
- **眼底**：后极部视网膜下积液、Dalen-Fuchs结节
- **病程**：进展期、恢复期（晚霞样眼底）、复发期

### 黄斑疾病

**中心性浆液性脉络膜视网膜病变（CSC）**
- **特点**：中青年男性多见，单眼或双眼发病
- **表现**：视物变形、变小、中心暗影、色觉异常
- **眼底**：黄斑区浆液性视网膜神经上皮脱离
- **FFA**：典型"炊烟征"荧光渗漏
- **自限性**：多数可在3-6月自愈

**黄斑裂孔**
- **分类**：全层裂孔、板层裂孔
- **表现**：中心暗点、视物变形
- **治疗**：玻璃体切除术（Ⅱ期以上）

**Epi视网膜膜（ERM）**
- **表现**：视物模糊、视物变形、复视感
- **眼底**：黄斑区金箔样反光
- **治疗**：观察或玻璃体切除术

### 视神经疾病

**视神经炎**
- **病因**：多发性硬化（MS）、视神经脊髓炎（NMO）、感染
- **表现**：急剧视力下降、眼球转动痛、视野缺损
- **体征**：RAPD阳性、视乳头充血或正常

**前部缺血性视神经病变（AION）**
- **分类**：动脉炎性（非动脉炎性）
- **表现**：无痛性视力下降、视野缺损
- **体征**：视乳头水肿、充血

**视乳头水肿**
- **病因**：颅内高压、全身疾病
- **表现**：进行性视力下降、复视
- **体征**：双侧视乳头肿胀、出血

### 玻璃体疾病

**玻璃体后脱离（PVD）**
- **表现**：飞蚊症、闪光感
- **并发症**：视网膜裂孔、视网膜脱离
- **处理**：需详查眼底，排除裂孔

**玻璃体积血**
- **病因**：PDR、视网膜裂孔、NVG、外伤
- **表现**：突发视力下降、漂浮物增多
- **治疗**：根据病因，必要时玻璃体切除术

### 视网膜退行性疾病

**Stargardt病**
- **特点**：青少年发病，常染色体隐性遗传
- **表现**：视力进行性下降、中心暗点
- **眼底**：黄斑区萎缩，呈"牛眼"样外观
- **FFA**：脉络膜湮灭征

**Best病（卵黄样黄斑营养不良）**
- **分期**：卵黄期、脱色素期、瘢痕期、萎缩期
- **诊断**：EOG检查 Arden比降低

**视网膜色素变性（RP）**
- **特点**：进行性夜盲、视野缩窄
- **眼底**：骨细胞样色素沉着、血管变细、视乳头蜡黄
- **治疗**：低视力康复、基因治疗探索中

## 鉴别诊断要点

### 出血性病变鉴别
| 疾病 | 出血特点 |
|------|---------|
| DR | 微血管瘤基础上的出血 |
| RVO | 沿静脉分布，范围局限 |
| 高血压视网膜病变 | 后极部火焰状出血 |
| NVG | 新生血管破裂，玻璃体积血 |

### 黄斑水肿鉴别
| 疾病 | 病因 |
|------|------|
| DME | 糖尿病 |
| 视网膜静脉阻塞 | 静脉回流障碍 |
| CSC | 脉络膜渗漏 |
| 葡萄膜炎 | 炎症 |

### 视乳头水肿鉴别
| 疾病 | 特点 |
|------|------|
| 颅内高压 | 双侧、进展性 |
| 视神经炎 | 单侧多见、眼球转动痛 |
| AION | 动脉硬化相关 |
| 葡萄膜炎 | 前房/玻璃体炎症 |

## 检查方法汇总

1. **视力、验光**：评估矫正视力
2. **眼压**：排除青光眼
3. **裂隙灯检查**：眼前节评估
4. **散瞳眼底检查**：发现病变
5. **眼底照相**：记录病变
6. **OCT**：评估黄斑、视神经结构
7. **FFA**：显示血管渗漏、无灌注区
8. **OCTA**：无创血管成像
9. **视野检查**：评估视功能
10. **全身检查**：血糖、血压、免疫指标等

## 就诊建议

当出现以下情况时，应及时就诊眼科：

1. **突然视力下降**：特别是无痛性的
2. **眼前漂浮物突然增多**：可能提示视网膜裂孔
3. **闪光感**：可能提示玻璃体牵引或视网膜裂孔
4. **幕状或窗帘样黑影遮挡**：可能为视网膜脱离前兆
5. **视物变形**：可能为黄斑病变
6. **夜盲进行性加重**：可能为视网膜病变
7. **视野缺损**：可能为青光眼或视神经疾病
8. **眼红、眼痛、畏光**：可能为葡萄膜炎或角膜疾病
