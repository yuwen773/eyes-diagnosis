# 高血压视网膜病变（Hypertensive Retinopathy）

## 概述

高血压视网膜病变（Hypertensive Retinopathy）是全身性高血压在小动脉病变在眼底的局部表现。长期高血压可导致视网膜血管硬化、血管痉挛、渗出、出血等病理改变。眼底检查不仅是诊断高血压视网膜病变的重要手段，也是评估全身血管损害程度的重要窗口。

## 发病机制

### 血管改变
1. **血管痉挛期**：小动脉功能性收缩，血管壁暂时性改变
2. **血管硬化期**：血管壁玻璃样变性、纤维化
3. **血管退行性变**：动脉壁纤维组织增生，管腔狭窄

### 病理过程
- 血-视网膜屏障破坏
- 血管渗漏增加
- 视网膜缺血缺氧
- 新生血管形成（恶性高血压）

## Keith-Wagener-Barker分级

根据病变严重程度分为四级：

### Ⅰ级
- 眼底表现：视网膜小动脉轻度变窄、硬化
- 动静脉比例（A/V）：正常2:3变为1:2
- 症状：通常无自觉症状

### Ⅱ级
- 眼底表现：
  - 动脉显著变窄、弯曲
  - 动静脉交叉压迫征（AV nicking）
  - 铜丝样或银丝样动脉
- 症状：通常无自觉症状

### Ⅲ级
- 眼底表现：
  - 视网膜水肿、出血（火焰状、点状）
  - 棉绒斑（缺血性神经纤维层梗死）
  - 硬性渗出
- 症状：视力下降、视物模糊

### Ⅳ级
- 眼底表现：
  - 视乳头水肿
  - Ⅲ级所有改变
  - 极严重者可出现渗出性视网膜脱离
- 症状：显著视力下降，可伴头痛、恶心

## 诊断要点

### 眼底检查特征
1. **动脉改变**
   - 血管变窄、迂曲
   - 血管壁改变：铜丝样、银丝样动脉
   - 动静脉交叉改变：交叉压迹

2. **视网膜改变**
   - 出血：火焰状、点状、视网膜前出血
   - 棉绒斑：边界模糊的灰白色斑块
   - 硬性渗出：边界清晰的黄白色小点
   - 水肿：视网膜雾样肿胀

3. **视乳头改变**
   - 视乳头水肿
   - 边界模糊

### 辅助检查
- **OCT**：评估视网膜层间水肿、神经纤维层厚度
- **FFA**：显示血管渗漏、无灌注区
- **全身评估**：血压监测、心肾功能检查

## 鉴别诊断

| 疾病 | 特点 |
|------|------|
| 糖尿病视网膜病变 | 微血管瘤、渗出更弥漫，无交叉压迫征 |
| 视网膜静脉阻塞 | 沿静脉分布的出血，静脉迂曲扩张 |
| 视神经炎 | 视乳头充血肿胀，视力下降明显 |
| 颅内高压 | 双侧视乳头水肿，无动脉硬化表现 |

## 与其他疾病的关系

### 糖尿病合并高血压
- DR和HRP可同时存在
- 鉴别诊断需综合考虑
- 两者协同加重视网膜血管损害

### 心脑血管疾病
- 高血压视网膜病变程度与心脑血管事件风险正相关
- 眼底血管评估可预测心血管死亡率
- 视网膜微血管损害可反映脑部微血管状态

## 治疗方案

### 全身治疗（根本治疗）
- **控制血压**：目标血压<140/90mmHg
- **改善生活方式**：
  - 低盐饮食（<6g/日）
  - 适度运动
  - 控制体重
  - 戒烟限酒
- **降压药物**：ACEI、ARB、CCB、β受体阻滞剂等

### 眼科对症治疗
- **原则**：眼科治疗不能替代全身血压控制
- **黄斑水肿**：抗VEGF治疗或糖皮质激素治疗
- **视网膜新生血管**：全视网膜光凝（针对缺血区）

## 预后

- 良性高血压视网膜病变：血压控制后，眼底改变可部分恢复
- 恶性高血压视网膜病变：视乳头水肿消退后，仍可能遗留视力损害
- 规律随访：监测血压和眼底病变进展

## 患者教育要点

1. **强调血压控制的重要性**：这是改善眼底病变的根本
2. **健康生活方式**：低盐饮食、适度运动、戒烟
3. **规律用药**：遵医嘱服用降压药物，不可随意停药
4. **定期复查**：眼底检查评估病变进展
5. **识别危险信号**：突然视力下降、眼前黑影飘动
