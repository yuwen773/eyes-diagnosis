# 病理性近视（Pathological Myopia，PM）

## 概述

病理性近视（Pathological Myopia，PM）又称高度近视性视网膜病变，是指眼轴过度延长（>26.5mm）导致的眼底退行性改变，其特征性改变包括后巩膜葡萄肿、漆裂纹、Fuchs斑、脉络膜新生血管（CNV）等。病理性近视是亚洲人群重要的致盲原因之一，在我国患病率约为1-2%。

## 定义与分类

### 眼轴分类（参考2015年META-PM分类）
- **低度近视**：-3.0D以下
- **中度近视**：-3.0D ~ -6.0D
- **高度近视**：-6.0D以上
- **病理性近视**：出现典型眼底退行性改变

### 眼底病变分类（META-PM）

**弥漫性脉络膜萎缩（DCA）**
- 早期改变，后极部脉络膜萎缩
- 可见于10-20%的高度近视

**斑块状脉络膜萎缩（PCA）**
- 进展期，局灶性脉络膜萎缩
- 萎缩区内可见大血管和巩膜

**黄斑萎缩（MA）**
- 晚期，累及黄斑中心
- 视力预后极差

## 特征性眼底改变

### 后巩膜葡萄肿
- **定义**：眼球后极部局限性扩张
- **部位**：常累及视乳头周围和黄斑区
- **诊断**：B超、OCT显示后巩膜局部前突

### 漆裂纹（ lacquer cracks）
- **外观**：不规则线状黄白色病灶
- **部位**：黄斑区、视乳头周围
- **意义**：Bruch膜破裂，是CNV发生的危险因素

### Fuchs斑
- **外观**：圆形或椭圆形黑色斑块
- **部位**：黄斑区中心或旁中心
- **形成**：脉络膜萎缩、色素上皮增生

### 脉络膜新生血管（CNV）
- **类型**：
  - 1型CNV：位于RPE下
  - 2型CNV：位于神经上皮下
- **表现**：中心暗点、视物变形、突发性视力下降
- **诊断**：FFA、OCT、OCTA

### 视网膜劈裂
- **部位**：后极部、周边部
- **表现**：可无症状，或出现闪光感、漂浮物
- **并发症**：可进展为裂孔、脱离

### 格子样变性
- **外观**：视网膜变薄、格子样外观
- **好发部位**：颞侧周边部
- **风险**：可发展为裂孔、视网膜脱离

## 并发症

1. **孔源性视网膜脱离（RRD）**
   - 风险因素：格子样变性、玻璃体牵引、CNV膜破裂
   - 表现：闪光感、漂浮物增多、幕状黑影遮挡

2. **黄斑裂孔**
   - 发生率：高度近视中约0.5-1%
   - 表现：中心暗点、视物变形

3. **青光眼**
   - 高度近视是青光眼的危险因素
   - 需定期监测眼压和视野

4. **白内障**
   - 高度近视患者白内障发病年龄提前
   - 核性白内障多见

5. **斜视**
   - 常见于病理性近视
   - 可出现外斜视或知觉性外斜视

## 诊断要点

### 常规检查
1. **屈光检查**：明确近视度数
2. **眼轴测量**：IOL Master、眼科A超
3. **眼底检查**：散瞳详细检查后极部和周边部
4. **眼底照相**：记录病变范围

### 影像学检查
1. **OCT**：
   - 评估黄斑结构
   - 检测CNV、劈裂、黄斑水肿
   - 监测病变进展

2. **OCTA（OCT血管造影）**：
   - 无创显示脉络膜新生血管
   - 评估血管形态和范围

3. **FFA**：
   - 经典CNV诊断方法
   - 显示渗漏活动性

4. **眼科B超**：
   - 显示后巩膜葡萄肿
   - 评估眼轴和后极部结构

## 治疗方案

### 近视控制
- **角膜塑形镜（OK镜）**：适用于近视进展较快的儿童
- **低浓度阿托品滴眼液**：0.01-0.05%
- **多焦点软镜/离焦镜片**：周边离焦设计

### CNV治疗（抗VEGF治疗）
- **一线治疗**：玻璃体腔注射抗VEGF药物
- **常用药物**：
  - 雷珠单抗（Ranibizumab）
  - 阿柏西普（Aflibercept）
  - 康柏西普（Conbercept）
- **治疗方案**：初始每月一次，连续3次，后按需治疗

### 激光治疗
- **激光光凝**：适用于周边部视网膜裂孔
- **光动力疗法（PDT）**：已少用，仅用于特定CNV

### 手术治疗
- **后巩膜加固术**：减缓眼轴进展（适用于进展期）
- **玻璃体切除术**：黄斑裂孔、劈裂相关并发症
- **视网膜复位术**：孔源性视网膜脱离

## 随访建议

| 病变状态 | 随访间隔 |
|---------|---------|
| 单纯高度近视，无眼底病变 | 1年 |
| 存在早期眼底改变 | 6月 |
| CNV治疗后 | 1-3月 |
| 曾发生RRD | 3-6月 |

## 患者教育要点

1. **避免剧烈运动和头部震动**：减少视网膜脱离风险
2. **警惕"危险信号"**：闪光感、漂浮物增多、幕状黑影
3. **避免用力揉眼**：减少对眼球的机械压力
4. **规律作息**：避免过度用眼
5. **均衡饮食**：富含叶黄素、维生素A的食物有益于视网膜健康
6. **心理支持**：病理性近视为慢性进展性疾病，需正确认识疾病
