# 05 — 迁移普通聊天与当前会话记忆

**What to build:** 用户继续创建和管理聊天会话，收到流式回答，后续消息能使用本会话已有内容；其他用户和其他会话的事实不会自动混入。

**Blocked by:** 01 — 建立可复现的现有 FastAPI 业务基线。

**Status:** completed — 2026-10-13；实现、契约与证据见 `docs/chat-session-memory.md`，双轴独立审查见 `docs/chat/issue05-review.md`。仅完成本票相关部分，真实服务整体验收另计。

**Spec:** Python Agent 迁移与眼底诊断工作流 Spec（2026-10-12）。

**Acceptance mapping:** AC-02、AC-03、AC-14、AC-15；本票完成所列判据的相关部分，不代表提前通过整个 spec。

- [x] 现有会话、历史、附件与聊天流式契约有明确对账并由 Python 承接，原聊天页面可完成多轮会话。
- [x] 历史内容实际进入模型上下文，使用可控模型验证第二轮能引用第一轮信息，不能只保存数据库或传 threadId。
- [x] 服务端检查会话与附件归属，跨用户访问被拒绝，其他会话症状不自动成为本次事实。
- [x] 消息、必要执行状态和审计自动保存，不要求逐条批准；重建应用后仍可载入原会话。
- [x] 普通问答不启动整套诊断，正常流结束和错误可区分；外部模型失败不写成完整成功回答。
